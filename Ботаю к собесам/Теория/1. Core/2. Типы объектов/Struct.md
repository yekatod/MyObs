
---
Тип значения который инкаплусирует данные и связанные функции. Класс для нищих.

public struct Coords
{
    public Coords(double x, double y)
    {
        X = x;
        Y = y;
    }

    public double X { get; }
    public double Y { get; }

    public override string ToString() => $"({X}, {Y})";
}

---


Структуры нужны для хранения маленьких, простых, неизменяемых данных, чтобы не создавать лишние объекты в [[Heap]] и не нагружать GC.

- readonly - желательно юзать ваще его + прописывать свойства как ридонли чтобы избежать неконтролируемых изменений
