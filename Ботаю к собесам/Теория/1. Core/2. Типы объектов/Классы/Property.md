## Свойство

---
Механизм для чтения записи или вычисления значения поля класса. Отражаются как открытые элементы данных, но семантически реализуются как специальные методы, называемые аксессорами

---
### Главное отличие

>Поле — это непосредственно хранящееся состояние объекта, а свойство — механизм доступа к состоянию, который при необходимости может содержать дополнительную логику.

| Поле                              | Свойство                      |
| --------------------------------- | ----------------------------- |
| Хранит данные                     | Предоставляет доступ к данным |
| Нет `get/set`                     | Есть `get/set/init`           |
| Не может содержать логику доступа | Может содержать логику        |
| Обычно `private`                  | Обычно `public`               |
|Может быть `ref`-возвращаемым|Имеет accessor'ы|
---

Автоматически реализованные свойства
```C#
public int Age {get;set;}
```

Метод доступа без явной  инициализации поля:
```C#
public int? Age { get; set => field = value < 18 ? -1 : value; }
```

`Init` аксессор используется для свойств, значения которых можно задать только из конструктора или инициализатора объекта.

---

**Backing field** — поле, которое используется свойством для хранения значения.
