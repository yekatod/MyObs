Встроенный универсальный [[Delegate]] с параметром/параметрами и возвращает указанный тип. Может принимать до 16 параметров + тип возвращаемого значения.

```C#
Func<string, string> selector = str => str.ToUpper();
```

Где `Func<input, return>` принимает сначала тип параметра, затем - тип возвращаемого значения
