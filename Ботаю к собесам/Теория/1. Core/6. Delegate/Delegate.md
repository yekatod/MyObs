
---

`Делегат` - тип, который представляет собой ссылку на метод с определённым списком параметров и типом возвращаемого значения. В делегат можно "вложить" любой метод, имеющий идентичную сигнатуру. Метод можно вызывать при помощи экземпляра делегата. Их используют для передачи методов другим методам в качестве аргументов. 

Пример

```C#
public delegate int PerformCalculation(int x, int y);
```

Причём назначаемый метод может быть из любого класса или структуры, статичным или методом экземпляра. Это позволяет гибко подсоединять код к существующим классам.
