Выражение для упрощённого создания анонимного метода

```C#
(input) => expression
```

Или
```C#
(input) => { actions }
```

Любое лямбда-выражение можно преобразовать в [[Delegate]]
Можно преобразовывать в `Expression<T>` (например, `Expression<Func<int, int>> f = x => x + 1;`), что позволяет LINQ-провайдерам (типа Entity Framework) читать код лямбды как данные и переводить его в SQL.
