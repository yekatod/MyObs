
## Делегат многоадресной рассылки


---

Добавить метод => `delegate += methodName`
Убрать метод => `delegate -= methodName`

Методы исполняются в порядке добавления

Возвращается результат только самого последнего добавленного метода

Если было выброшено исключение - остальные методы не будут вызываться (если не перехватывать исключения изнутри)

Работают совместно с [[Event]]
