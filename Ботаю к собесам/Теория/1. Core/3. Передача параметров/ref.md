
---

Передает параметр в метод путём передачи ссылки. Разрешены чтение и запись

---

Нельзя использовать в связке в:
- [[async]]  методе
- методе с [[yield]] return оператором
---

Для использования явно указывать `ref` у параметра метода
```C#
void Method(ref int refArgument) 
{ 
	refArgument = refArgument + 44; 
}
```
