## Частичный класс


Позволяет разделить определения класса, структуры, интерфейса на несколько определений (в рамках разных файлов в одном проекте)

Каждый файл содержит раздел определения типа

Нужны если:
- над классом работает несколько людей одновременно
- добавление кода в класс без изменения сгенерированного (например WPF)

У таких классов объединяются:
- Атрибуты
- Комментарии XML
- интерфейсы
- члены
