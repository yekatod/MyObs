## Стек против кучи
---

| Параметр              | STACK                                                   | HEAP                                                                                             |
| --------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Что в основном хранит | Значимые типы                                           | Ссылочные типы                                                                                   |
| Скорость              | Более быстрый за счёт простоты (LIFO)                   | Более медленный, потому что объекты могут быть разбросаны в адресном пространстве неупорядоченно |
| Доступ из потоков     | К нему имеет доступ только один поток, он более локален | К нему могут иметь доступ бесчисленное число потоков, глобален                                   |
| Очистка               | Очищаются фреймы (автоматически)                        | [[Garbage Collector]] или руками                                                                 |
| Объём                 | 1 мб                                                    | от 32бит (ваще задаётся при старте приложения)                                                   |
| Ошибки                | Stack overflow                                          | OutOfMemory                                                                                      |
| Использование         | Локальные переменные и функции                          | Динамические объекты                                                                             |
