## Свойство

---
Механизм для чтения записи или вычисления значения поля класса. Отражаются как открытые элементы данных, но семантически реализуются как специальные методы, называемые аксессорами

---

Автоматически реализованные свойства
```C#
public int Age {get;set;}
```

Метод доступа без явной  инициализации поля:
```C#
public int? Age { get; set => field = value < 18 ? -1 : value; }
```

`Init` аксессор используется для свойств, значения которых можно задать только из конструктора или инициализатора объекта.
