
---
Класс - ссылочный тип данных, определяющий схему для объектов.

---

Использовать когда:
- Тип имеет сложное поведение
- Необходимо использовать наследование/расширение
- У экземпляров общая идентичность
- Длительный срок жизни, большой размер

---

Переменная, инициализировавшая экземпляр
```C#
var c = new Customer("Oleg");
```
хранит в себе только ссылку

Тут-то и отличие от [[Struct]], потому что структуры копируют данные при присваивании, а классы копируют ссылку. Также из различий - классы позволяют юзать наследования. 

---

Инициализаторы полей назначают значение по умолчанию

```C#
public class Customer
{
	private int _age = 18;
}
```

Параметры конструктора требуют чтобы проставлялись значения (обязательно)
```C#
public class Customer
{
	private int _age;
	
	public Customer(int age) => _age = age;
}
```

Основные конструкторы
```C#
public class Customer(int age)
{
	private int _age = age;
}
```

Обязательные свойства
```C#
public class Customer
{
	private requirred int Age {get;set;}
}
```

Класс может быть [[static]], если он не может быть создан как экземпляр и содержит только статические члены. Работает в качестве служебных методов (примеры уже существующие - `Math` и `Console`)

Инициализатор
```C#
Customer customer = new{
	Age = 18
};
```
