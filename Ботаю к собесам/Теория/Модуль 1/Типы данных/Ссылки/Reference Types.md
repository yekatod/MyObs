## Ссылочные типы

---
Переменные таких типов хранят ссылки на их значения, в отличие от [[Value Types]], которые хранят непосредственно сами значения. Таким образом, ссылочные типы позволяют нескольким объектам хранить ссылку на один и тот же экземпляр, т.е. операции с такой переменной приводят к **изменению экземпляра для всех переменных, хранящих ссылку на него**

---

Примеры:
- [[Class]]
- [[Interface]]
- [[Delegate]]
- [[record class]]

Также встроенные:
- [[dynamic]]
- [[object]]
- [[string]]

---

- Участвуют в процессе сборки мусора
- Могут быть null
- Создаются в [[Heap]]

---
При инициализации объекта например класса выделяется место в куче под сам объект, а также место в [[Stack]] под указатель. При выходе из метода фрейм уничтожается, а вот сам объект уничтожается при помощи [[Garbage Collector]]

---

При передаче экземпляра в метод в [[Stack]] выделяется новый фрейм и туда передаётся ССЫЛКА на экземпляр. При создании нового объекта в копии меняется и ссылка. Однако при передаче экземпляра в метод с модификатором [[ref]] мы передаём ссылку и в таком случае операции над объектом осуществляются над ССЫЛКОЙ над ССЫЛКОЙ над объектом, т.е. при инициализации нового объекта и наш объект поменяется

> >Пример #1
> 
	public class Toy { public string Name }
	public void Start()
	{
	var Toy = new Toy { Name = "Test";}
	ProcessToy(Toy);
	}
	 public void ProcessToy(Toy toy)
	 {
	 toy = new Toy {"Toy"};
	 }

в этом примере у нас ссылка на экземпляр сохранится, т.к. Toy в `ProcessToy` является копия исходного `toy` из метода `Start`. Т.е. в таком случае у нас новую ссылку получает копия, а не оригинальный объект. Но стоит только добавить `ref`
> >Пример #2
> 
	public class Toy { public string Name }
	public void Start()
	{
	var Toy = new Toy { Name = "Test";}
	ProcessToy(ref Toy);
	}
	 public void ProcessToy(ref Toy toy)
	 {
	 toy = new Toy {"Toy"};
	 }

Так тут в метод `ProcessToy` попадает уже непосредственно ссылка на первоначальный Toy из [[Stack]] и соответственно та же ячейка памяти будет уже ссылаться на новый `Toy` с Name = "Toy"
